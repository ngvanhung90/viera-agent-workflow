# Ví dụ tổng hợp / Synthetic example

Demo uses one fixed [project map](PROJECT_MAP.md), [ChatGPT packet](Gui_ChatGPT_DEMO.md) and [task record](TASK.md). The identifiers are invented. The example illustrates revision, identity and direct checkpoint lookup. It does not confer writer rights or supply a live receipt.

For an existing project, map these roles to the files or tickets already in use. The binding locates sources; [the shared policy](../AGENTS.md) defines the obligations.
